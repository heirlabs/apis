## GitHub Issues (this repo)

Use issues for:

- Documentation bugs and missing guides  
- Example scripts that fail against production  
- Clear, reproducible API/doc mismatches  

Please use an issue template and redacted payloads only.

Do **not** use issues for:

- Account recovery or billing disputes  
- Legal advice about a will/estate  
- Security vulnerabilities (see [SECURITY.md](./SECURITY.md))  

## Response expectations

This is an open documentation repository maintained alongside a production product.
We triage issues as capacity allows. Critical production outages should go through
[status.heir.es](https://status.heir.es) and product support, not only GitHub.
