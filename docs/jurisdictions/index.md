# Jurisdictions

HEIR supports inheritance frameworks across 190+ jurisdictions. Use the list below or query the structured data endpoint at `/structured/jurisdictions.json`.

## Regions

- `/jurisdictions/by-region/north-america`
- `/jurisdictions/by-region/europe`
- `/jurisdictions/by-region/middle-east`
- `/jurisdictions/by-region/asia-pacific`
- `/jurisdictions/by-region/latin-america`
- `/jurisdictions/by-region/africa`

## Search

For programmatic lookup, use:

```http
GET https://docs.heir.es/structured/jurisdictions.json
```
