# Islamic Law (Sharia)

HEIR supports Quranic inheritance (Mirath) along with Wasiyyah and Waqf structures. The system enforces fixed shares and optional bequests in accordance with Sharia constraints.

## Components

- **Mirath**: fixed shares for heirs (Fara'id)
- **Wasiyyah**: bequest up to 1/3 of estate to non-heirs
- **Waqf**: charitable endowment structures

## API Usage

```json
{
  "inheritanceTemplate": "islamic-mirth"
}
```
