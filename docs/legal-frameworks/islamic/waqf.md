# Waqf (Charitable Endowment)

Waqf dedicates assets to charitable or religious purposes. HEIR models Waqf as a locked allocation with governance rules.

## Core Rules

- Endowment is **irrevocable** once established
- Beneficiaries receive proceeds, not principal
- Often used for long-term charitable purposes

## API Usage

```json
{
  "inheritanceTemplate": "islamic-waqf",
  "waqf": {
    "beneficiary": "charity",
    "percentage": 20
  }
}
```
