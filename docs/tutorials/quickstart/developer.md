# Quickstart: Developer

## Goal

Generate your first contract via API.

## Steps

1. Create an API key at [heir.es/developers](https://heir.es/developers) → [heir.es/developers/keys](https://heir.es/developers/keys).
2. Call `/api/v1/contracts/templates`.
3. Call `/api/v1/contracts/generate`.
4. Deploy with your own chain client; HEIR does not publish a REST SDK.

See [Product paths](/guide/product-paths) and [Quick Start](/guide/quickstart).
